# ÉPOQUE — The Time-Travel Fashion Magazine

> 1985년 서울의 가상 패션지 **ÉPOQUE(에포크)** 가 매 호 한 시대로 출장을 떠나, 그 시대의 옷을 화보로 찍어 온다는 설정의 프로젝트.

**사이트 보기:** https://ejdms499-wq.github.io/epoque-magazine/

## No.01 — PARIS 1925

첫 출장지는 1925년 파리. 표지부터 백스테이지까지 21페이지 구성.

| 페이지 | 내용 |
|---|---|
| 01 | 표지 |
| 02–03 | 오프닝 · 1925년 파리의 밤 |
| 04–05 | 에디터 레터 · 1985년 편집부의 출장 일지 |
| 06–11 | WOMEN · 룩 01–05 (이브닝 드레스, 데이 수트, 테니스, 로브 드 스틸, 이브닝 코트) + 뷰티 |
| 12–13 | 디테일 · 여성 액세서리 |
| 14–19 | MEN · 룩 01–04 (시티 수트, 화이트 타이, 골프 웨어, 리비에라) + 그루밍, 이번 호의 아홉 벌 |
| 20–21 | 남성 액세서리 · 백스테이지 |

## 기획 포인트

- **시간여행 출장 화보**: 1985년 편집부의 시점으로 1925년의 옷을 바라보는 에디터 노트
- **스타일링 크레딧**: 룩마다 아이템 명칭·소재·고증 노트 정리
- **같은 해, 세 개의 실루엣**: 일자(플래퍼) · 벨(로브 드 스틸) · 스포츠
- **비주얼 톤**: 1980년대 일본 만화 일러스트(시티팝) 그림체, 코발트·앰버·크림 팔레트
